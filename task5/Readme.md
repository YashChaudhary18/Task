5. Duplicate Numbers (Java)

 Overview :

This Java program finds and prints duplicate numbers from a given array.

Input array:

{1, 2, 3, 2, 5, 1}

Output:

Duplicate numbers: 1, 2

---

 Features :

- Uses nested loops to compare elements
- Identifies duplicate values
- Prints duplicate numbers

---

 Example Output :

Duplicate numbers are:
2
1

---

 Logic Explanation :

- Outer loop selects each element
- Inner loop compares it with remaining elements
- If a match is found → it's a duplicate
