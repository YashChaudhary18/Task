# Task

 Java Practice Projects (Task 1 - 6)

 Overview :

This repository contains a collection of Java programs designed to build a strong foundation in core programming concepts.

Each task focuses on a specific concept such as:

- Basic logic building
- String handling
- Object-Oriented Programming (OOP)
- Collections (ArrayList)
- Problem solving
- Mini project development

---

 Project Structure :

Java-Tasks/
│
├── task1/  → Number Operations
├── task2/  → String Handling
├── task3/  → Student Class (OOP)
├── task4/  → ArrayList Practice
├── task5/  → Duplicate Numbers
├── task6/  → Employee Management System (Mini CRUD)

---

 Tasks Overview :

 Task 1 – Number Operations

- Check if a number is Prime or Not
- Check if a number is Even or Odd
  Concepts: Conditions, Loops, Logic

---

 Task 2 – String Handling

- Reverse a string
- Count number of vowels
  Concepts: Strings, Loops, Methods

---

 Task 3 – Student Class

- Create a Student class with id, name, marks
- Use constructor, getters/setters
  Concepts: OOP, Encapsulation

---

 Task 4 – ArrayList Practice

- Store student names using ArrayList
- Print all names
- Search a name
  Concepts: Collections, Loops, Logic

---

 Task 5 – Duplicate Numbers

- Find duplicate elements in an array
  Concepts: Nested loops, Problem solving

---

 Task 6 – Employee Management System

- Add employee
- View employees
- Delete employee
  Concepts: OOP, ArrayList, Real-world logic

---

 Technologies Used

- Java (JDK 8+)
- Core Java Concepts
- Collections Framework

---

 Key Learnings

- Strong understanding of Java fundamentals
- Writing clean and modular code
- Applying OOP concepts
- Working with collections
- Building mini console-based applications
