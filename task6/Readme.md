6. Employee Management System (Java)

 Overview :

This is a simple console-based Employee Management System built using Java.

The application allows users to:

- Add new employees
- View all employees
- Delete an employee by ID

---

 Features :

- Menu-driven console interface
- Add employee (id, name)
- View employee list
- Delete employee by ID
- Uses ArrayList for dynamic storage

---

 Project Structure :

task6/
 ├── Employee.java
 └── EmployeeManagement.java

---

 Example Menu :

--- Employee Management ---
1. Add Employee
2. View Employees
3. Delete Employee
4. Exit

---

 Concepts Used :

 OOP

- "Employee" class represents employee data
- Encapsulation using private variables

 ArrayList

- Dynamic storage of employees

 Logic

- Menu-driven program using loops and switch-case
