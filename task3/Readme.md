3. Student Class (Java)

 Overview :

This project demonstrates basic Object-Oriented Programming (OOP) concepts in Java by creating a "Student" class.

The program allows:

- Creating a student object
- Storing student details (id, name, marks)
- Displaying student information

---

 Features :

- Uses Constructor to initialize student data
- Implements Encapsulation using private variables
- Provides Getter and Setter methods
- Displays student details using a method

---


 Example Output :

Id: 1
Name: Yash
Marks: 72.5

After Updating Marks:
Id: 1
Name: Yash
Marks: 80.0

---

Concepts Used :

 Class and Object

- "Student" class is used to create objects
- Object stores individual student data

Constructor

- Initializes object values at the time of creation

 Encapsulation

- Data members are declared as "private"
- Accessed using getter and setter methods

 Methods

- "displayDetails()" is used to print student data
