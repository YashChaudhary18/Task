4. ArrayList Practice (Java)

 Overview :

This Java program demonstrates the use of "ArrayList" from the Collections Framework.

The program performs the following operations:

- Stores 5 student names in an ArrayList
- Prints all student names
- Searches for a user-entered name

---

Features :

- Dynamic list using "ArrayList"
- Iteration using loops
- Search functionality using basic logic
- User input using "Scanner"

---

 Example Output :

Student Names:
Yash
Rahul
Amit
Neha
Priya

Enter name to search: Rahul
Name found in the list

Enter name to search: Karan
Name not found in the list

---

 Concepts Used :

 ArrayList

- A resizable array that can grow dynamically
- Allows storing multiple values

 Loop

- Used to iterate and print elements

 Search Logic

- Compares user input with list elements using loop
