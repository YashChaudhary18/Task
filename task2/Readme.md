🔤 String Handling (Java)

📌 Overview

This Java program performs basic string operations:

- Reverse a string
- Count number of vowels in the string
- Display string length

This project helps in understanding string manipulation and loop logic in Java.

---

🚀 Features

- Takes user input using "Scanner"
- Reverses the string
- Counts vowels (both uppercase and lowercase)
- Displays string length

---



💡 Example Output

Enter String: Hello World
String length is 11
Reverse String: dlroW olleH
Number of vowels: 3

---

🧠 Logic Explanation

Reverse String

- Loop runs from last character to first
- Characters are appended in reverse order

Vowel Count

- Each character is checked against vowels (a, e, i, o, u)
- Both uppercase and lowercase are considered
