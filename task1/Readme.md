🔢 Number Operations (Java)

📌 Overview

This is a simple Java console-based program that performs basic number operations:

- Checks whether a number is Prime or Not
- Checks whether a number is Even or Odd

This project is useful for beginners to understand:

- Conditional statements ("if-else")
- Loops
- Methods
- Basic logic building in Java

---

🚀 Features

- User input using "Scanner"
- Prime number checking
- Even/Odd checking
- Clean and modular code using methods

---


💡 Example Output

Enter Number: 7
Number is Prime
Number is Odd

Enter Number: 10
Number is NOT Prime
Number is Even

---

🧠 Logic Explanation

Prime Number Logic

- A number is prime if it has only 2 divisors: 1 and itself
- We check divisibility from "2" to "√n" for optimization

Even/Odd Logic

- If a number is divisible by 2 → Even
- Otherwise → Odd
